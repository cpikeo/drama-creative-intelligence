# Director-Level Drama Creative Intelligence · Unified Professional Package · v5

一个**总导演、一套持续记忆、一个可演化世界、一条完整影视创作链**。
它不是多 Agent 岗位拼装、剧本模板、提示词库、网站模板、UI Design System 或组件库。唯一创作中枢是 **Creative Director / Director Core**，统一 Story、World、Character、Visual、Storyboard、Image、Video、Sound、Edit、Continuity、Production、QA 与按需的 Presentation / Editorial Art Direction。

## 完整能力链

```text
Understand → Remember → Reason → Decide → Direct → Generate → Verify → Update Memory
理解 → 世界观 → 故事 → 角色 → 视觉 → 分镜 → 图像 → 视频 → 声音 → 剪辑 → 连续性 → 创意验收
```

- **Director Intelligence**：关键问题以 `Evidence → Context → Alternatives → Trade-off → Decision → Consequence → Verification` 主动取舍；`DEC-L` 承担可逆局部取舍，`DEC-H` 承担会影响跨集真相的持久决定。
- **Evidence Boundary**：每项证据带类型、来源定位、置信与可用范围；生成媒体只能先作为证据，媒体事实必须经 `真实媒体检查 → MEDIA QA → DEC-H` 才能晋升 Canon/State。
- **Causal Memory**：所有有后果的行动遵循 `Choice → Event → State Delta → Consequence → New Constraint → Future Pressure`，让今天的选择持续限制明天的人物、关系、资源与 Promise。
- **长期记忆**：`World Bible / Character Bible / Visual Bible / Narrative Canon / Events / Relationships / Foreshadowing / Assets / Directorial Intent`；Promise 使用 `Seeded → Activated → Pressured → Narrowed → Redefined → Fulfilled / Abandoned` 生命周期。
- **跨集控制**：World State、State Snapshot、最小 Snapshot Diff、Character DNA 与 Continuity Graph 共同约束下一集；Graph 以 `causes / changes / limits / enables / knows / believes / holds / owes / promises / fulfills / contradicts` 推演后果。
- **最小 Context**：只加载当前任务所需的 Canon/Intent、Snapshot、角色/资产、Graph 邻接、Promise 与媒体；因果、人物动机与制作边界已足够时停止扩展。
- **变化与复用**：`Change → Dependency Graph → Stale Scope → Recheck`；`stale` 只要求重新判断，优先 `Re-read → Re-plan → Reuse → Edit → Regenerate`；仅当核心身份、事实、动作、信息、情绪或交付受损才重生成。
- **导演级生成与验收**：以独立的 `SPEC QA / MEDIA QA / CUT QA` 审核文本、真实媒体与成片；实际媒体用 `Intent → Attention → Information → Emotion → Expectation` 判断叙事、视听、连续性与商业完成度，而非只看任务成功。
- **按需 Presentation Intelligence**：故事圣经、Lookbook、提案、角色册、分镜展示、发行物与 deck 使用同一记忆派生，不另立真相。

## 使用方式

```text
从一句话开发 8 集 9:16 动态漫剧：替人收拾残局的实习生，
在公司直播事故中发现所有人的“好意”都指向同一份伪造数据。
以 Director-Level Drama Creative Intelligence 建立 World/Character/Visual Bible、Narrative Canon、
Character DNA、伏笔、EP001 Snapshot 和 Continuity Graph，再完成可生产的第一集。
不要套身份反转模板；先让观众看见她的旧策略失效。
```

```text
继续 EP004：读取上一集 Snapshot、与女主有关的 Character DNA、PROMISE 和 Graph 邻接节点，
推演父亲雨夜出现后她的关系和资产状态。她不原谅父亲，但替他撑一次伞。
更新剧本、状态、分镜、声画规格、剪辑和下一集 Snapshot；列出需要补拍的媒体，不要自动投产。
```

```text
基于已接受的 Canon 和 Visual Bible，为制片方制作一份项目 Lookbook 与 10 页合作提案。
先确定 Audience、Objective、Message 和 Insight；每页只保留一个视觉重心，
只使用能证明故事、世界、角色或制作价值的剧照/图表/资产。页面表达不能改写世界事实。
```
