# 导演判断手册：故事、Character DNA、电影语言与声画生成

只在当前任务需要时读取。它是导演判断的词汇和边界，不是模板、镜头配额或提示词库。任何规则不能取代当前故事、Character DNA、World State、创作者意图与真实媒体观察。

## 1. 世界、故事与人物：从因果而非套路出发

故事发动机回答：主角反复争取什么？阻力为什么不能绕过？每一轮如何改变权力、信息、关系、暴露、资源、时间或代价？什么变化会终结这台机器？世界规则只保留会改变行动、风险、关系或视听的规则。

- 场景通常形成 `议程 → 对抗策略 → 方向性转折 → 退出状态`；日常、仪式、氛围、蒙太奇或余波无需假造对手，但必须改变知识、关系、压力、节奏或状态。
- 一集从可感进入点开始，先兑现局部承诺，再留下来自当前结果的出去压力。结尾可峰值、留白、反讽或安静余韵，不必机械追加事件。
- 改编区分来源事实、创作新增、解释与假设。压缩/合并/换载体保住核心人物立场、行动方式、关系、主线因果和信息权限。
- 不把两难、取证、倒计时、有限次数、系统、身份反转、高潮、VO 或特写当作默认结构。它们只有在题材和人物已使其必要时才出现。

## 2. Character DNA：人物连续性高于外观连续性

每个关键角色用以下可演化 DNA 判断：

| DNA 层 | 必须能回答 |
|---|---|
| **Identity** | 他是谁、不可替换的身份/背景/能力/声音/命名锚点是什么？ |
| **Psychology** | 欲望、恐惧、盲点、旧策略、底线、羞耻/自尊/信念如何影响选择？ |
| **Visual DNA** | 可辨脸/体态、稳定造型、声音身份、代表物、能力/伤痕和可变体分别是什么？ |
| **Relationship** | 对谁相信、利用、亏欠、害怕、爱、对立；双方各知什么、能动用什么？ |
| **Arc State** | 当前处于旧策略、受压、退缩、选择、付价、重组还是新策略阶段？ |

人物变化必须记录 `变化前 → 触发事件/选择 → 代价或结果 → 变化后 → 生效范围`。关键行动先通过：`Want（想要）→ Know（知道/未知）→ Leverage（筹码）→ Pressure（压力）→ Choice（真实选项）→ Cost（代价）→ visible Action（可见行动）`。任一环为空，先补人物前因、信息或压力，不得用“剧情需要”强迫角色改变。服装、伤痕、持物、能力、情绪、立场、关系和成长不能因为新镜头/新 prompt 而自动重置。对话让人物争取、回避、试探、交换、逼迫或改写关系；能用动作、距离、眼线、物件、停顿和呼吸表现的内容，不用解释替代。

## 3. 电影语言：镜头只为观看任务存在

每镜先确定一个 `Primary Function`：建立、发现、关系、权力、行动、反应、信息、转场或节奏；可有辅助功能，但必须写 `Do Not Repeat`，避免与其他镜重复同一信息/反应。删掉它观众仍不失去什么，就删、合并或换表达载体。

每场还写一条观众任务：`看见什么 / 误解什么 / 担心什么 / 等待什么`，只选当前场真正需要的项。每镜要能回答：来源场景/事件；观众应接收什么；景别、机位、构图、空间/眼线；人物/道具/表情的准确起点；一个主要动作；终点；光源/光态；声音；转场；连续性与参考依据。

- **景别**：远景建立尺度、孤立、秩序；中景承载策略和关系；近景仅在细节改变理解时进入。景别变化不按远中近轮换，也不为漂亮插入无关眼/手特写。
- **构图/空间**：先锁入口出口、固定结构、动作轴、人物方向、视线和可达路径；前/中/后景、遮挡、留白、物件和框景引导注意。未知背面、建筑拓扑、产品结构不为反拍方便而伪造。
- **机位/运动**：固定镜头也是选择。推拉、横移、摇摄、升降、变焦、拉焦、主体移动和环境运动要分别说明相对谁、为何、到哪里停；一个片段默认一个主要事件和一个主要运镜。
- **光影/色彩/材质/景深**：光来自窗、灯、屏幕、天气、火或反射；色来自世界、关系、时间或材质；焦点落在关键信息。黑部保留信息，亮部有层次，质感克制可信；不以宽黑边、滤镜、颗粒、霓虹或暗黑冒充电影感。
- **转场/节奏**：硬切、静帧、留黑、匹配、声音桥、省略和重建空间各有功能。动作/视线/声音/状态必须被接住；有意不连续要声明例外性质与回归锚点。

## 4. 图像、视频与声音：导演意图的可追溯编译

### 图像与关键帧

资产/参考图规格只写当前用途：`用途 → Identity/Visual DNA/锁 → 当前变体 → 视角/构图 → 光色/材质/时代 → 必要背景/文字 → 有意义限制`。关键帧冻结单一边界：起始帧不提前出现终点结果；收尾帧只在制作确实消费时建立。图中可见角色、地点和道具必须回指 Canon/State。

### 视频

视频规格：`静态锚点（文生必写） → 准确起点 → 主变化/触发/接触/落点 → 必要反应 → 摄影机 → 声音时间线 → 准确终点`。图生视频只描述首帧之后的变化，但仍声明 Character DNA、连续性锁和当前状态。不同机位的相邻镜头通常是剪辑，不是假装摄影机穿墙连续运动。

### 声音

声音记录来源、时段、语言与戏剧功能：
- 对白/VO/OS：剧本原文、说话人、发声窗口、表演意图；
- 环境：空间、天气、距离、持续/中断；
- SFX：物理事件与注意重点；
- 静默：关系、威胁、反应或转场需要的可听留白；
- 音乐：进入/退出、动态、与对白/表演的关系。

无对白镜说明环境或静默。没有用户提供/接受歌词时不写歌词；画内文字与非画内字幕分开，视频不自行生成字幕、caption、logo 或对白叠字。

### 制作形态

静态漫剧、关键帧切换、有限动态、图生视频、文生视频和混合媒介由戏剧功能、媒介能力和预算决定。静态画面可由构图、配音、环境声和剪辑成立；不要为了“视频化”制造无意义运动，也不要让音乐代替表演。

## 5. 剪辑与导演级验收

先完整看/听真实媒体，标记可用带：表演何时成立、何处漂移、动作回弹、口型失真、画面发白、声音断裂或信息重复。入点在观众需要开始看时进入，出点在信息完成且缺陷开始前离开；剪辑能调节节奏、色/声接缝、字幕和响度，但不能静默改写剧本、镜头职责或 Canon。

最终连续观看：静音检验画面叙事，闭眼检验声音逻辑，正常检验情绪、人物、节奏、连续性和回报。将结论分开写为 `SPEC QA`、`MEDIA QA`、`CUT QA`；没有实际观看/聆听就只能通过前者，后两者不能宣布成片通过。

## 6. Presentation / Editorial Art Direction：让项目被准确地理解（仅按需）

故事圣经、Lookbook、项目提案、角色册、分镜展示、发行封面或投资/合作 deck 是 Director Memory 的**派生传播层**，不是另一套创作脑。只在用户要求时制作；它们可改变如何说明作品，不能静默改写 Canon、Character DNA、World State 或 Directorial Intent。

先判断：

`Audience → Objective → Message → Insight → Visual Concept → Focus → Information Weight → Spatial Structure → Composition → Media`

- **Audience / Objective**：谁看、已知什么、要做何种理解/决策/行动；不是“把资料做漂亮”。
- **Message / Insight**：每份材料有一个核心主张；每页有一句可检验结论和一个主视觉重心。结论、证据、条件、来源不能拥有同等音量。
- **Visual Concept**：从本剧的 Canon、媒介、时代、角色和 Directorial Intent 推导色彩、类型、材料、图像距离与版式语气；不是另贴“高级/科技/电影感”滤镜。
- **Spatial Structure / Composition**：阅读路径、网格、比例、对齐、留白、裁切和文本/媒体关系服务焦点。卡片墙、厚容器、无意义边框、阴影、渐变、图标和装饰默认删除，除非它们承担信息或叙事职责。
- **Media**：图片、图表、角色图、剧照、视频、材质或动效只在提供证据、语境、尺度、情绪、过程或品牌表达时存在。无任务的媒体删掉；画内事实、角色状态、产品/空间结构仍服从 Canon。

借鉴 Swiss Typography 的清晰层级、FT/Bloomberg 的事实与数据责任、McKinsey Editorial 的结论/论证、Apple/Aesop/Pentagram 的材料/比例/品牌语气，以及电影语言的观看立场、空间压力、真实光影、色彩与景深；这些是判断尺度，不是可复制的表面风格。图表和文字必须诚实可读，颜色不应是唯一编码；电影感不得把明亮资料、数据页或项目图强行变暗、宽银幕化或影视化。

交付前以 3 秒/10 秒/30 秒检查：先看到的焦点是否正确？是否能说出本页结论和证据？条件、来源和下一步是否仍可读？实际导出未查看时，只能声明设计已检查，不能称演示已通过。
