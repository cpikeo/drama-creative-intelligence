# 导演判断手册：故事、人物、镜头与声音

按需读取，只读相关章节。这里是判断的词汇与检验方法，不是模板、镜头配额或提示词库。任何规则都不能取代当前故事、DNA、State、创作者意图与真实媒体观察。

## 1｜故事与因果

**创意发动机示意**（只示范检验方式，勿复用）：实习生替上司顶下直播事故，却发现每个人的“好意”都指向同一份伪造数据。主题：善意如何变成责任的转移。矛盾：她越替人兜底，越证明自己不可替代，也越没有被允许犯错的余地。机制：她的每一次帮忙都以她的签名入档，成为别人掩护的凭证。情绪论点：被照顾的人最难拒绝照顾。
检验：把“签名入档”换进另一部办公室剧，戏还成立吗？拿掉它，故事还能被别人说出吗？两问都为“否”，发动机才成立。

- **场的结构**：议程 → 对抗策略 → 方向性转折 → 退出状态。日常、仪式、氛围、蒙太奇与余波可以没有对手，但必须改变知识、关系、压力、节奏或状态之一。
- **观众任务**：每场写一条——看见什么、误解什么、担心什么、等待什么，只选当前场真正需要的。
- **一集**：从可感的进入点开始；先兑现局部承诺，再留下来自当前结果的出去压力。结尾可以是峰值、留白、反讽或安静余韵，不必机械追加事件。
- **下一场测试**：下一场能否由上一场的出去压力推出？不能，则补出去压力，或在别处找借因；不写过场戏。
- **套路检测**：两难、取证、倒计时、有限次数、身份反转、系统流、高潮、VO、特写等，不作默认结构；只在题材与人物已使其必要时出现。检验观众猜测的来源：来自人物则保留，来自题材则打破。
- **改编**：区分来源事实、创作新增、解释与假设。压缩、合并或换载体时，保住核心人物立场、行动方式、关系、主线因果与信息权限。
- **对白经济与潜台词**：一句台词只承担一件事（信息、情绪或关系）；复述画面已有的内容禁止；多余的解释删到不影响理解为止（经验值约三成，非硬规则）。能用动作、距离、物件或静默完成的，不用台词。人物不说满，真实意图藏在另一个话题或动作之下。
- **VO/OS**：信息权限装置。只能携带该场视点人物所知；不用全知旁白补观众应等待的信息。
- **口头习惯**（口头禅、称呼）按 Voice DNA 的自然频率出现，不成口头病。

## 2｜角色 DNA 判断

| 层 | 必须能回答 |
|---|---|
| Identity | 不可替换的身份、背景、年龄锚点、能力与命名标志是什么？改了为什么就不像他？ |
| Psychology | 欲望、恐惧、盲点、旧策略、底线与信念怎样驱动选择？遇到同类问题，他通常怎么解？盲点会在哪场反噬？ |
| Visual | 可辨脸与体态？固定发型与改变条件？服装系统（时代、风格、标志件、磨损）？伤痕的来源、现状与愈合时间线？标志道具的持有链？能力的可见表现与限制？各状态变体指向哪个事件、何时还原？ |
| Voice | 音色（音高、厚度、明暗、质感）？语速基线与节奏习惯（停顿，情绪时加速或拖拍）？口吻？呼吸模式？哭、怒、压抑、平静时声音如何变化？配音锁（音色 ID、参数、口音）？口头禅与称呼？ |
| Relationship | 对谁相信、利用、亏欠、害怕、爱、对立？双方各知什么？各有什么筹码与债务？上一事件后变了什么？ |
| Arc State | 处于哪一阶段？依据什么因果？下一事件把哪个阶段推向哪里？ |

- **稳定性**：同一角色跨集保持同一张脸、同一服装基线、同一音色、同一语速基线、同一口吻。情绪改变表演，不改变身份。无事件、无 DEC 的换声、变音或参数漂移，按身份漂移处理。状态变体是派生状态，不是新身份。
- **表演是弧线的可见形式**：知道弧线阶段的观众，应能预判表演基调，并偶尔被惊到。可预期处可预期，值得惊到处才惊。
- **角色替换测试**：换成另一个人，戏仍成立，则人物缺席；应出现的是此角色 DNA 独有的行动、台词或选择。
- **声音指纹**：同一角色面对同类压力时，说话方式、停顿与呼吸应长自其旧策略。

## 3｜电影语言

每镜先确定一个主要功能：建立、发现、关系、权力、行动、反应、信息、转场或节奏。有辅助功能时写下 `Do Not Repeat`（不重复的信息或反应）。删掉它，观众是否失去一个具体的东西？失去不了，就删、合并或换载体。

- **静止帧测试**：停在任一帧，构图、光、色与信息各自成立。只靠运动成立，是廉价运动。
- **元素服务测试**：光、色、材质、运动、景深、SFX 逐一问服侍谁。说不出即装饰，删。克制是边际递减点：先问“是否已经够了”，再问“能否更好看”。
- **景别**：远景建立尺度与秩序；中景承载策略与关系；近景只在细节改变理解时进入。景别不按远中近轮换，不为漂亮插入无关的眼或手特写。
- **空间与构图**：先锁入口出口、结构、动作轴、人物方向、视线与可达路径；前中后景、遮挡、留白与框景引导注意。未知背面、拓扑与产品结构，不为方便而伪造。
- **机位与运动**：固定镜头也是选择。运动须说明相对于谁、为何、停在哪里；每段默认一个主事件与一个主运动。无目的的慢推、手持、环绕、升格或变速一律删除。
- **光**：每盏光有动机（窗、灯、屏幕、天气、火、月光、反射）与方向；同场同时段的软硬、衰减与色温一致。光态是 STATE，按变化规则更新。无动机的夜景不成立；为画面漂亮而跳变光态，属身份级缺陷。
- **色彩与材质**：色板来自世界、时代、材质、关系与时间。材质须可信于媒介：无塑料感，无过饱和糖色；黑部保留信息，亮部有层次。焦点落在关键信息上，不一定落在脸上；拉焦只在转移注意时使用。
- **表演**：表情起点可读（在想什么），变化有触发（看到、听到、想起），终点是状态。写可见的动作，不写“她很伤心”。心理外化于姿态、重心、手与呼吸；受压者与付完价者的姿态不同。走位（动作线、距离、物件互动）表达权力与关系，距离的靠近或远离必须有事件。停顿是表演，不是空场。节奏上，动作有节奏，反应有节拍。反应镜头只在提供新信息、新情绪或权力变化时切入。
- **转场**：硬切、静帧、留黑、匹配、声音桥、省略与重建空间，各有功能。动作、视线、声音与状态须被接住；有意的不连续须声明性质与回归锚点。
- **统一影像语言**：一部作品一套时代锚点、媒介质感、色板、光逻辑与构图习惯。整集或整季的 look 变化（色温、颗粒、媒介）须有事件或导演意图，并记 DEC；单场的光色处理按光态规则办。禁止“为好看换风格”。
- **象征系统**：符号（反复出现的物件、手势、色彩）是压缩的因果断言。意义在全作品中唯一；只有新的因果断言出现，才新增符号；改义即 INTENT 变化，记 DEC。
- **美学锚点**：3–6 张创作者认可的 REF 剧照，各自声明锚定维度（调色、质感、光逻辑、构图、媒介质感），锚点本身须经检查。多件媒体单件合格、整体偏离时，先问“锚点错了，还是造出锚点的判断错了”；改锚点记 DEC，并重验按旧锚点比对过的媒体。
- **反伪电影感**：没有明确观看意图时删除：宽黑边、胶片颗粒、霓虹与暗黑基调、伪光学光晕与色散、罐头“电影感”配乐、为压暗而压暗。电影感来自动机光、真实材质、有目的的运动与正确的表演，不来自滤镜。

### 高画质基线（生成下限，也是 MEDIA QA 的验收线）
- **光学行为**：折射、阴影、遮挡与纵深正确，无穿模。
- **皮肤与质感**：无塑料、蜡像或油光；纹理匹配景别。
- **解剖稳定**：手指、关节、耳与牙的比例稳定，跨镜不漂移。
- **几何一致**：同一物件、空间、服装的形状、结构与磨损一致。
- **文字可读**：画内文字正确，无乱码或半成形字。
- **无 AI 漂移**：无脸漂、服装撕裂、背景闪烁、物件数量跳变。
- **光影连续**：同场光源方向、色温与对比一致，跨镜连续。

## 4｜从判断到规格

### 一致性三件套
- **定妆参考（REF）**：A 级角色建立时，生成并检查正面、侧面与表情组（3–5 张），登记为 REF 并纳入 Visual Bible。此后生成该角色须传入参考图（工具支持参考输入时必须使用）。参考图变更即 Visual DNA 变更，记 DEC。
- **IDENTITY 块写满**：下装、面部毛发、伤痕的侧别与位置（如“左腕内侧，画面右侧”）、配饰（工牌写“无字”）。未写的细节，模型会自行补全，验收时须补入锁。
- **三块规格**（人物描述只能由块拼装，禁止现写重述）：
  - `IDENTITY`（固定）：脸、体态、年龄锚点、发型、标志特征，取自 Visual DNA，跨镜跨集文本一致；
  - `STATE`（派生）：当前变体、伤痕、持物、光态，取自 State；
  - `SHOT`（派生）：景别、视角、动作、表情、视线、构图，取自镜头卡。
  块与 DNA 或 State 不一致时，错在块，不在 DNA。
- **负面锁**：A 级角色与关键镜头列出“不得出现”项：限定镜或集的排他服装与道具、禁入的第三方、禁止的风格漂移。负面锁即 LOCK。

### 镜头卡（一镜一卡；进入生成前字段须齐，未进入生成的镜头可缺三块规格）
`SH-ID · 来源场与事件 · 观众接收 · 主功能与 Do Not Repeat · 景别、机位、构图 · 人物、道具、表情的起点 · 一个主要动作与终点 · 光态（引用状态表）· 声音（对白、环境、SFX、静默、音乐）· 转场 · 连续性依据 · 参考 · 三块规格`

### 各类规格
- **图像与关键帧**：按 `用途 → Identity 与锁 → 当前变体 → 视角与构图 → 光色、材质与时代 → 背景与文字 → 限制` 书写。起始帧不提前出现终点结果；收尾帧只在制作确实消费时建立。画内文字（工牌名、红章字、招牌）不由生成模型完成：规格写“无字”，需要的文字由剪辑叠字。去字、补伤痕、修连接等局部问题先用编辑（输入原图，只写改动）；风格或身份整体漂移才重生。
- **视频**：`静态锚点（文生必写）→ 准确起点 → 主变化、触发、落点 → 必要反应 → 摄影机 → 声音时间线 → 准确终点`。图生视频只描述首帧之后的变化，仍须声明 DNA、锁与状态。相邻的不同机位通常是剪辑，不是假装摄影机穿墙连续运动。
- **声音**：对白写原文、说话人、发声窗口与表演意图，引用 Voice DNA 与本镜情绪偏差（偏差只改表演层，不改身份层），音色锁按 LOCK 执行。环境、SFX、静默与音乐各记来源、时段与戏剧功能。没有用户提供或确认的歌词，不写歌词。视频不自行生成字幕、logo 或对白叠字；画内文字与字幕分开。
- **声音圣经**（每作品一份，入 Visual Bible）：每个 LOC 的环境声基线为 LOCK；角色或主题的音乐动机为 LOCK（同一动机即同一旋律与配器）；响度目标按平台交付规格；同一物理事件即同一 SFX 身份。
- **先配音还是先画面**：导演决定。契约期或单集定一次并记 DEC，不得逐镜混用。
- **提示词卫生**：不出现受保护作品名、角色名或商标，以原创描述替代。授权原著只携带契约确认的边界事实。

### 媒介形态的镜头语法与运动预算

| 媒介 | 镜头语法与运动预算 |
|---|---|
| 静态漫剧 | 零运动；叙事由构图、对白、SFX 与剪辑承担 |
| 动态漫 | 每镜至多一个运镜，仅推、拉、摇、移；无手持、无环绕；人物为有限动态（口型、发丝、衣摆、光） |
| 图生视频 | 3–5 秒窗口；一个主事件加一个主要反应；声明 DNA、锁与状态 |
| 文生视频 | 静态锚点必写；不假设首帧 |
| 拟真实拍 | 真实摄影逻辑：动机光、真实景深、无夸张运动 |

## 5｜剪辑

先完整看、听真实媒体，标出可用带：表演何时成立，何处漂移，动作何处回弹，口型何处失真，何处发白，声音何处断裂，信息何处重复。入点在观众需要开始看的时刻，出点在信息完成、缺陷开始之前。剪辑可以调节节奏、色声接缝、字幕与响度，但不能静默改写剧本、镜头职责或 Canon。

连续观看三遍：**静音**检验画面叙事，**闭眼**检验声音逻辑，**正常**检验情绪、人物、节奏、连续性与回报。
