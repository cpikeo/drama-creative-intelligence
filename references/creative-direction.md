# 导演判断手册：故事、Character DNA 与电影语言

只在写故事、人物、镜头或声音规格前按需读取，且只读相关章节。它是导演判断的词汇与边界，不是模板、镜头配额或提示词库。此处任何规则不能取代当前故事、Character DNA、World State、创作者意图与真实媒体观察。

## 1. 世界、故事与人物：从因果而非套路出发

创意发动机（五要素，SKILL §02 生成侧）必须通过四个动力学检验：主角反复争取什么？阻力为什么不能绕过？每一轮如何改变权力、信息、关系、暴露、资源、时间或代价？什么变化会终结这台机器？世界规则只保留会改变行动、风险、关系或视听的规则。

- 场景通常形成 `议程 → 对抗策略 → 方向性转折 → 退出状态`；日常、仪式、氛围、蒙太奇或余波无需假造对手，但必须改变知识、关系、压力、节奏或状态。
- 一集从可感进入点开始，先兑现局部承诺，再留下来自当前结果的出去压力。结尾可峰值、留白、反讽或安静余韵，不必机械追加事件。
- 改编区分来源事实、创作新增、解释与假设。压缩/合并/换载体保住核心人物立场、行动方式、关系、主线因果和信息权限。
- 不把两难、取证、倒计时、有限次数、系统、身份反转、高潮、VO 或特写当作默认结构。它们只有在题材和人物已使其必要时才出现。
- **下一场预测测试**：下一场必须由上一场的出去压力推出。若从当前状态推不出下一场，则上一场缺出去压力，或下一场在别处借因——补其一，不写过场戏糊弄。
- **原创性推理（怎么检测与打破）**：观众的猜测依据分两种——来自人物（必然，保留）或来自题材（套路，打破）；Trade-off 只剩 A/B 时先写出 **A 与 B 共享什么前提**（通常只有一个，如“揭示必须当面发生”“主角必须知道真相”）；Option C = 打破共享前提且仍服务主题的第三种表达，并答出它为何从发动机长出。
- **情绪架构（怎么落图）**：每个情绪节拍记 `人物做了什么选择 → 观众此前信什么 → 现在信什么 → 欠/还了什么情绪`；节拍间的积累与释放按观众体验链（SKILL 生成侧）；场次局部形式 = 观众任务（§3）；不承载人物选择的情绪节拍是滤镜，删。

## 2. Character DNA：每层必须能回答什么

DNA 六层结构、行动门与变化规则已固定于 SKILL §03，本节只深化各层的判断标准，不重述定义。

| DNA 层 | 必须能回答 |
|---|---|
| **Identity** | 他是谁？不可替换的身份、背景、年龄锚点、能力、声音与命名标志是什么？为什么改了就不像他？ |
| **Psychology** | 欲望、恐惧、盲点、旧策略、底线与羞耻/自尊/信念如何驱动选择？他的常设策略是什么（遇到同类问题通常怎么解）？ |
| **Visual DNA** | 可辨脸/体态与年龄锚点？固定发型与改变条件？服装系统（时代/风格/标志件/磨损状态）？伤痕与旧伤（来源事件、当前状态、愈合时间线）？标志道具及其持有链？能力的可见表现与限制？状态变体（受伤/淋湿/战斗/丧期）各自指向哪个事件、何时还原？ |
| **Voice DNA** | 音色（音高/厚度/明暗/质感）？语速基线与节奏习惯（停顿、情绪时的加速或拖拍）？口吻（温和/粗粝/冷淡/温吞、习惯性语气）？呼吸模式（浅/深、屏息、呼吸作为情绪标志）？哭、怒、压抑、平静时声音各如何变化？固定配音参数（TTS 音色 ID 与参数锚点、口音）？口头禅与称呼习惯？ |
| **Relationship** | 对谁相信、利用、亏欠、害怕、爱、对立？双方各知什么？各能动用什么筹码与债务？上一次事件后这段关系变了什么？ |
| **Arc State** | 当前处于 旧策略 / 受压 / 退缩固化 / 选择 / 付价 / 重组 / 新策略 的哪一阶段？依据是什么因果？下一个事件将把哪个阶段推向什么？ |

**稳定性原则**：

- 跨集同一角色 = 同一张脸、同一套服装系统基线、同一音色、同一语速基线、同一口吻；情绪改变表演，不改变身份。
- 配音参数是连续性锁（`LOCK`）：同一角色的 TTS 音色 ID 与参数锚点固定；无事件、无 `DEC-H` 的换声、变音或参数漂移属于身份漂移，按缺陷处理。
- 状态变体是派生状态而非新身份：每个变体必须指向触发事件与还原条件。
- 行为先看策略：同一角色面对同类压力，行为应长自其旧策略；策略升级必须完成 Arc State 过渡（选择 → 付价 → 新策略），不能由新 prompt 直接换掉。
- 对话让人物争取、回避、试探、交换、逼迫或改写关系；能用动作、距离、眼线、物件、停顿和呼吸表现的内容，不用解释替代。

**变化判断**：任何变化必须能回答三问——为什么此时必须变、人物付出什么代价、影响哪些下游镜头/声音/道具/后续因果；三问答不出，变化不成立（记录格式见 SKILL §03 变化规则）。

**角色替换测试**：写戏时把此角色换成另一个；若戏仍成立，则人物缺席——该出现的应是此角色 DNA 独有的行动/台词/选择。**表演是 Arc State 的可见形式**：知道此角色弧线阶段的观众，应能预判其表演的基调，并偶尔被惊到——可预期处可预期，值得惊到处才惊。

### 对白与 VO

- 一句线只干一件事：信息、情绪或关系推进，三选一定主次，默认砍 30%；复述画面已显示的台词禁止。
- 潜台词：人物不说满；真实意图藏在另一个话题、另一个动作下面。
- 对白经济：能用动作、距离、物件或静默完成的一句，不用台词。
- VO/OS 是权限装置不是拐杖：VO 只能携带该场视点人物所知（绑定信息权限）；不用全知旁白补观众应等待的信息。
- 口头习惯（口头禅/称呼）按 Voice DNA 自然频率出现，不成口头病。

## 3. 电影语言：镜头只为观看任务存在

每镜先确定一个 `Primary Function`：建立、发现、关系、权力、行动、反应、信息、转场或节奏；可有辅助功能，但必须写 `Do Not Repeat`，避免与其他镜重复同一信息/反应。删掉它观众仍不失去什么，就删、合并或换表达载体。

每场还写一条观众任务：`看见什么 / 误解什么 / 担心什么 / 等待什么`，只选当前场真正需要的项。每镜要能回答：来源场景/事件；观众应接收什么；景别、机位、构图、空间/眼线；人物/道具/表情的准确起点；一个主要动作；终点；光源/光态；声音；转场；连续性与参考依据。

**静止帧测试**：此镜停在任何一帧，仍必须是完整画面——构图、光、色彩、信息各自成立；只靠运动才成立的画面是廉价运动。**元素服务测试**：光、色、材质、运动、景深、SFX 逐一问它服侍什么（人物/信息/情绪/空间/节奏）；说不出服侍对象即装饰，删。克制 = 边际递减点：“是否已经够了”先于“能否更好看”。

### 景别与构图

- **景别**：远景建立尺度、孤立、秩序；中景承载策略和关系；近景仅在细节改变理解时进入。景别变化不按远中近轮换，也不为漂亮插入无关眼/手特写。
- **构图/空间**：先锁入口出口、固定结构、动作轴、人物方向、视线和可达路径；前/中/后景、遮挡、留白、物件和框景引导注意。未知背面、建筑拓扑、产品结构不为反拍方便而伪造。

### 机位与运动

固定镜头也是选择。推拉、横移、摇摄、升降、变焦、拉焦、主体移动和环境运动要分别说明相对谁、为何、到哪里停；一个片段默认一个主要事件和一个主要运镜。**无意义运动** = 没有信息或情绪目的的运动：无目的慢推、无目的手持晃动、无目的环绕、无目的升格/变速一律删除；有意运动（例外）走 SKILL 开篇例外条款。

### 真实光影

光来自窗、灯、屏幕、天气、火、月光或反射；每一盏光有动机、有方向，同一空间同一时段内软硬、衰减与对比一致。光态（时段、天气、进出光区）是 STATE：进入 Snapshot，按变化规则改变。无动机光的夜景（街灯/月光/屏光/烛火都不存在）不成立；为画面漂亮而跳变光态属于身份级缺陷。

### 色彩、材质与景深

色彩系统来自世界、时代、材质、关系与时间，Visual Bible 中有色板基线。材质感（布料/金属/皮肤/玻璃/植物/食物/武器）必须可信于媒介：无塑料感、无过饱和糖果色、质感克制可信；黑部保留信息，亮部有层次。焦点落在关键信息而非必然落在脸上；景深服务信息层级；拉焦只在转移注意时使用。

### 表演

- **微表情链**：表情起点可读（在想/感受什么），变化有触发（看到/听到/想起什么），终点是状态；不写“她很伤心”，写“她嘴角抽了一下，把杯柄转了两圈”。
- **心理外化**：姿态、重心、手、呼吸与步态承载人物当前心理与 Arc State；受压的角色和付完价的角色不该有同一套姿态。
- **走位**：动作线、距离、进出场与物件互动表达权力与关系变化；距离的靠近/远离必须有事件。
- **节奏**：动作有节奏、反应有节拍；停顿是表演，不是空场。
- **反应镜头**：只有当反应提供新信息、新情绪或权力变化时才切；不为反拍方便而切。

### 转场与节奏

硬切、静帧、留黑、匹配、声音桥、省略和重建空间各有功能。动作/视线/声音/状态必须被接住；有意不连续要声明例外性质与回归锚点。

### 统一影像语言

一部 Visual Bible = 一套影像语言：时代锚点、媒介质感、色板、光影逻辑、构图习惯与调色统一；同一空间、同一物件、同一角色跨集跨镜的长相稳定。任何单集/单场 look 变化（色温、颗粒、媒介质感）必须有事件或导演意图并记 `DEC-H`；禁止“为好看换风格”。

**象征系统**：符号（反复出现的物件/手势/色彩）是压缩的因果断言——全作品意义唯一，意义必须能从主题与因果史答出；只有新因果断言出现才新增符号；改变符号意义是 INTENT 变化，记 `DEC-H`。

**美学锚点**：Visual Bible 收录 3–6 张创作者认可的 REF 剧照，每张锚点声明其锚定的维度（调色/质感/光逻辑/构图/媒介质感）；锚点本身必须通过 REF 检查，未读、未验证的锚点不成立。锚点可被累积的真实媒体修正：多张媒体单张合格、整体却偏离锚点时，先问"锚点与造出锚点的判断，哪个错了"；改锚点是 `DEC-H`，改后所有已按旧锚点比对的媒体重新验收。审美世界观的修正维度含象征系统与视觉语法，不只调色与质感。

### 高画质基线

生成目标的下限，同时是 MEDIA QA 的验收线：

- **光学行为**：折射、阴影、遮挡、纵深关系正确，无穿模；
- **皮肤与质感**：皮肤自然，无塑料/蜡像/油光感，纹理细节匹配景别；
- **解剖稳定**：手指、关节、耳/牙比例稳定，跨镜头不漂移；
- **几何一致**：同一物件、空间、服装的形状、结构与磨损状态一致；
- **文字可读**：画内文字正确可读，无乱码或半成形字；
- **无 AI 漂移**：无脸漂、服装撕裂、背景闪烁、物件数量跳变；
- **光影连续**：同场光源方向、色温、对比一致，跨镜头连续。

### 反伪电影感

没有明确观看意图时默认删除：宽黑边/宽银幕、胶片颗粒、霓虹/暗黑基调、镜头光晕与色散等伪光学特效、罐头“电影感”配乐、把明亮素材强行压暗加黑边。电影感来自动机光、真实材质、有目的的运动和正确的表演，不来自滤镜。

## 4. 图像、视频与声音：导演意图的可追溯编译

### 人物与资产一致性三件套

- **定妆参考图（A 级角色）**：角色建立时生成并验收参考图（正面/侧面/表情组，3–5 张），锁为 `REF` 并记入 Visual Bible；此后该角色所有生成必须引用参考图；参考图变更 = Visual DNA 变更，走变化规则并记 `DEC-H`。
- **DNA → prompt 块**：人物描述只能由块拼装，禁止现写重写：

  ```text
  IDENTITY 块（固定）：脸/体态/年龄锚点/发型/标志特征，取自 Visual DNA；
      同一角色跨镜跨集文本相同，仅变化规则可改
  + STATE 块（派生）：当前变体/伤痕/持物/所在光态，取自 World State
  + SHOT 块（派生）：景别/视角/动作/表情/眼线/构图，取自镜头规格
  ```

  规格审查查块引用与锁匹配，不接受自由描述；块与 DNA/State 不一致时，错在块，不在 DNA。
- **负面锁（do-not 清单）**：A 级角色与关键镜头写“不得有”：排他服装/道具（限定某镜/某集）、禁出现物、禁入第三方、禁风格漂移。负面锁是 `LOCK` 记录，变更同样走变化规则。

### 图像与关键帧

资产/参考图规格只写当前用途：`用途 → Identity/Visual DNA/锁 → 当前变体 → 视角/构图 → 光色/材质/时代 → 必要背景/文字 → 有意义限制`。关键帧冻结单一边界：起始帧不提前出现终点结果；收尾帧只在制作确实消费时建立。图中可见角色、地点和道具必须回指 Canon/State。prompt 中不出现受保护作品名、角色名或商标字样，用原创描述替代；授权原著只携带契约确认的边界事实。

### 视频

视频规格：`静态锚点（文生必写） → 准确起点 → 主变化/触发/接触/落点 → 必要反应 → 摄影机 → 声音时间线 → 准确终点`。图生视频只描述首帧之后的变化，但仍声明 Character DNA、连续性锁和当前状态。不同机位的相邻镜头通常是剪辑，不是假装摄影机穿墙连续运动。

### 声音

声音记录来源、时段、语言与戏剧功能：

- **对白/VO/OS**：剧本原文、说话人、发声窗口、表演意图；引用该角色的 Voice DNA（音色/语速/口吻/呼吸锚点）与本镜情绪偏差——情绪偏差只改表演层，不改身份层；TTS 音色 ID 与参数跟随 Visual Bible 的配音参数锚点（`LOCK`）。
- **环境**：空间、天气、距离、持续/中断。
- **SFX**：物理事件与注意重点。
- **静默**：关系、威胁、反应或转场需要的可听留白。
- **音乐**：进入/退出、动态、与对白/表演的关系。

没有用户提供/接受歌词时不写歌词；画内文字与非画内字幕分开；视频不自行生成字幕、caption、logo 或对白叠字。

**声音圣经**（每作品/每季一份，记入 Visual Bible）：每个 `LOC` 的环境声基线是 `LOCK`（同空间同环境声身份）；角色/主题音乐动机是 `LOCK`（同一动机 = 同一旋律与配器）；响度与混音目标按平台交付规格；同一物理事件 = 同一 SFX 身份。

**TTS → 视频生产顺序**是导演级决定（`DEC-H`，契约期或单集定一次并记录）：先配后画（TTS 先行，视频对唇型与呼吸）或先画后配（视频先行，配音适配口型）；不得逐镜混用。

### 制作形态

媒介形态（静态漫剧、动态漫、有限动态、图生视频、文生视频、拟真实拍风）× 交付形态（短剧、剧集、广告、电影）在契约期确定（SKILL §04），由戏剧功能、媒介能力和预算共同定档。静态画面可由构图、配音、环境声和剪辑成立；不要为了“视频化”制造无意义运动，也不要让音乐代替表演。

分媒介形态的镜头语法/运动预算：

| 媒介形态 | 镜头语法 / 运动预算 |
|---|---|
| 静态漫剧 | 0 运动；叙事由构图、对白、SFX 与剪辑承担 |
| 动态漫 | ≤1 运镜/镜，仅推拉摇移；无手持、无环绕；人物动作为有限动态（口型/发丝/衣摆/光） |
| 图生视频 | 3–5s 窗口；一个主事件 + 一个主要反应；声明 Character DNA、锁与当前状态 |
| 文生视频 | 静态锚点必写；不假设首帧 |
| 拟真实拍风 | 真实摄影逻辑：动机光、真实景深、无夸张运动 |

## 5. 剪辑

先完整看/听真实媒体，标记可用带：表演何时成立、何处漂移、动作回弹、口型失真、画面发白、声音断裂或信息重复。入点在观众需要开始看时进入，出点在信息完成且缺陷开始前离开；剪辑能调节节奏、色/声接缝、字幕和响度，但不能静默改写剧本、镜头职责或 Canon。

最终连续观看用三遍检验：静音检验画面叙事，闭眼检验声音逻辑，正常检验情绪、人物、节奏、连续性和回报。三层 QA 的顺序、结论与问题格式固定于 SKILL §05-7 与记忆协议；剪辑只提交真实观看记录与可用带作为证据。
