# 记忆与生产协议：存储、读取、传播、生产、验收

本文件是 SKILL 的操作层：怎么存、怎么读、怎么传播、怎么生产、怎么验收。六种真相、判断规则与 DEC 标准只在 SKILL 中定义，这里不重复。事实只写一次；Context 只加载解决当前决定所需的节点。

## 1｜项目文件与角色记录

```text
<项目>/
├── 创作总控.md     # 能力声明 · 创作契约 · Bibles（世界、角色、视觉）· Canon · 承诺账 · INTENT · 图谱 · 资产与 LOCK · 各集 Snapshot
├── 剧集/EP001.md   # 剧本 · 镜头卡 · 状态表 · 规格 · 生产追踪 · 剪辑 · QA · Snapshot Diff · 图谱增量
└── 制作/EP001/     # REF、PLAN、MEDIA 文件与运行观察；不冒充 Canon
```

不预建空集，不按岗位拆文件。总控只存下游会依赖的可追溯事实与未决线索，不是百科；进入生产的项目须在总控写一节 `## 能力声明`（设计 / 执行 / 验证，见 SKILL §5），跨会话时它是判断验收上限的唯一依据。

## 2｜证据、决定与视点

- **证据**（用于 CANON、HYPOTHESIS、MEDIA 条目）：`ID · 类型（USER / CANON / HISTORY / MEDIA / QA / HYPOTHESIS）· 来源定位（文件、时间码或指令）· 置信 · 可支持与不可支持的用途`。创作者的直接指令可一行带过。
- **DEC**：字段见 SKILL §1。后果与验证点须指向具体的场、镜或媒体。
- **因果条目**（EVENT）：逐词写 `Choice → Event → State Delta → Consequence → New Constraint → Future Pressure`，每条都能反查它改变的状态与压迫的下游。写 CANON 或 STATE 事实时，挂到其 EVENT / REL / PROP 节点 ID（依赖以 ID 为准）。
- **视点时间**：场景与事件标注视点时间及其与当前的关系（现在、闪回、梦境、想象、未来）。闪回、梦境与想象是视点，不写 State；其中的信息进入相关角色的 knows 边与相关 PROMISE，不成为世界事实，除非剧情已确立该事件真实发生。
- **媒体证据**：生成文件只证明其中可见的内容。晋升为事实须经 SKILL §5 的媒体晋升门。
- **冲突**：先判类型与来源，再判断它是状态变化、信息误导、主观画面、创作者 retcon，还是错误（覆盖规则见 SKILL §2，此处不复述）。

## 3｜Snapshot 与状态表

Snapshot 是 T2（与已确定续集的 T1）的机制：单条与单集项目不维护跨集链，改为在总控保留"当前事实"即可。每集开头读入上集 Snapshot，结尾写出下集的 Snapshot：

```text
EP### Snapshot
前因：上集及更早仍在生效的事件与承诺；逐条引用上集“出去压力”的 ID（PROM、EDGE、CHG）
状态：世界、角色、关系、资产、时间与光态、观众知识
本集变化：谁因何事从什么变成什么
后果：已落地、不可逆或将限制下一行动的结果
未决：PROMISE、风险、误解、资源或信息缺口，及其责任人
```

结尾附 **Snapshot Diff**：只列新增、改变、移除的节点、边与 PROMISE 状态，不复述整卡。新剧本若违背上集 Snapshot，须写出事件、回忆、时间跳跃或 retcon 作为桥，不默默覆盖。

**状态表**（每集一张，是关键帧与视频规格的唯一光态源）：

```text
| SC/SH | 故事时间 | 距上场 | LOC | 光态（光源 / 时段 / 天气 / 色温） | 备注 |
```

光态变化即 STATE 变化。闪回场的时间是视点时间，不改变当前光态。规格按行引用本表，不另写自由文本光态。接缝的入点与出点按行引用本表与镜头卡（维度清单见手册 §3 跨镜接缝）；接缝状态变化按 SKILL §3 的变化规则记录，不静默改。物品的静动分类、当前位置与动作阶段同属 STATE（规则见手册 §3 静动逻辑），本表按镜记录其起止值，切镜不重置。

## 4｜Continuity Graph

- **ID**：图谱节点为 `CHAR- LOC- PROP- EVENT- REL- PROM- ASSET- SC- SH- MEDIA-`；边为 `EDGE-`（边的 ID 用于被引用，见 SKILL §3）；操作 ID 为 `LOCK- GEN- CUT- P- DEC-`、变更记录 `CHG-` 与 T0 事实清单行 `FS-`，后四项不入图谱节点。ID 指同一实体、事件或叙事职责：润色不换 ID；真正拆并实体或镜头时，记录替代关系。
- **边行格式**（T2 剧本定稿时逐行写增量；T1 只写本集实际引用的节点与边，T0 用 `FS-nn` 代替）：`EDGE-ID: 起点 — 动词 → 终点 | 来源（场或台词）| 前后状态 | 生效范围 | 观众已知？`
- **写场前反查**（结论写入镜头卡的“连续性依据”）：① 目标角色的 knows、believes（行为是否超出其知识）；② holds、owes（筹码是否成立）；③ 相关 PROMISE（本场推动还是回收）；④ 相关 LOC、PROP 的当前状态。查不到，先补记忆，再写场。
- **依据列**：对白表与镜头卡都写依据 ID。镜头依据须覆盖该镜全部对白的依据；依据变化时，只重做引用了它的台词。
- **状态传播**：变化规则的适用范围以 SKILL §3 为准。检查相邻镜，也检查远距离因果：早期交出的物件、获得的知识、留下的伤痕、未兑现的承诺，不能在后集凭空恢复或消失。

## 5｜变化传播

**切片加载**：当前任务 → 相关 CANON 与 INTENT → 上集 Snapshot → 相关角色与资产 → Graph 邻接 → 未兑现 PROMISE → 当前媒体。证据足以判断因果、动机与制作边界时即停止扩展；证据不足、因果跨越、人物行动无因、资产状态不明或状态冲突时，才扩展到相邻依赖。

**变更记录**：格式与分段见 SKILL §3（T2 六段全式，T0/T1 四段简式）；刷新结果另记 `已刷新 · 待刷新`。

| 变化源 | 至少重查 |
|---|---|
| CANON、世界规则、人物动机或关系、信息权限 | Snapshot、剧本与状态、信息释放、声音、媒体 |
| 美学锚点或 INTENT（DEC） | 按旧锚点比对过的全部媒体、Visual Bible、色彩/质感/光态规格、MEDIA 与 SPEC QA 结论 |
| DNA、资产身份、LOCK（含配音锁）、环境状态 | 相关变体、关键帧、prompt、参考、TTS 参数、后续镜与媒体 |
| 场景行动、对白、画内文字、声音 | 分镜、关键帧、视频、TTS、字幕、音乐、剪辑 |
| 镜头边界、时长、构图、声音 | 关键帧、视频规格、参考、剪辑续接 |
| prompt、模型、参考或参数 | 预览、未运行任务、相关媒体与续接 |
| 媒体或剪辑观察 | 剪辑与 QA；必要时回到规格、分镜、剧本或 State |
| Snapshot 或图谱边 | 下集 Snapshot Diff，及受影响节点的邻接 |
| 派生展示（P-） | 无；页面标 stale 与刷新规则见 Presentation 手册 |

**范围计算**：引用变化 ID 的行是候选；每个候选判为 `Re-read / Edit / Regenerate / 无需动作`，不按类别整批标记。枢纽节点（PROM、人物名）不沿其扩展，除非状态或回收条件变化。

**执行**：按 `Re-read → Re-plan → Reuse → Edit → Regenerate` 逐级处理。只有缺陷破坏身份、Canon、State、核心动作、必要信息、情绪意图或交付可用性时才重生成。用户要求同步时才递归刷新到规格与 QA；重投红线见 SKILL §5 生产门。

## 6｜生产与验收

**REF 登记**：相对路径、来源与授权、用途（身份、造型、地理、构图、起始、结束、风格或声音），以及可控与不可控范围。状态标记（`FACT · REF · PLAN · GEN · MEDIA`）含义见 SKILL §5，此处不复述。

**生产追踪**（集文件内，跨会话断点）：

```text
| 任务ID | 模态 | 规格ID | 输出（画幅 / 时长 / 帧率 / 响度） | 批次 | 状态 | 实际检查（看了、听了或测了什么） | 结论 | 失败层 | 最小修复 | 恢复点 |
```

`输出` 列从创作契约继承且不得留空：断点续作与 MEDIA QA 都按它比对交付规格。

每镜、每句对白、每段音乐一行。恢复中断时先读追踪，再决定下一步；已提交的结果先收集并检查，不盲目重投。状态为 `MEDIA` 的行，`输出` 列须与契约一致，不一致即媒体层缺陷。

**批次与共同原因**：按 3–5 镜一批生成与审查，每批过 MEDIA QA 再投下一批。批内系统性缺陷（同一张脸、服装或光态多镜同错）属共同原因：先修共同原因（块、参考、参数或状态表），重验 1 镜通过后再继续，不逐镜硬磕。

**授权**：批次确认的效力与失效条件见 SKILL §5 生产门；本层只补两点——确认须写明预计成本，确认与检查结果都写入追踪行。

**各模态失效清单**（MEDIA QA 逐项核对，记录项与结论）：
- **图像**：IDENTITY 块与 REF 一致 · 高画质基线 · 状态一致（变体、持物；伤痕与毛色侧别须按**画面侧**逐项核对，画面侧不明记为未验证）· 同 LOC 陈设与结构与锚点图一致 · 画内文字 · 美学锚点。
- **视频**：首帧等于已验收关键帧 · 主事件唯一 · 运动无跳变、无穿模 · 口型（有对白时）· 物件持久（不漂移、不瞬移、不改变数量）· 光影连续 · 出点与下一镜入点对齐 · 多段生成的接续帧一致或已桥接 · 时长闭合。
- **TTS**：音色锁（对白表 `voice_id` 与 ID、参数逐句一致）· 专名发音 · 韵律与表演意图 · 呼吸与房间声匹配 · 无朗读感（VO 与 OS 分开）。缺 `voice_id` 绑定的行记为未验证，不得记通过。
- **音乐**：动机锁 · 入出点 · 动态不盖对白 · 授权清楚。

**QA 记录**：三层结论与证据化问题写入集文件的 QA 节。问题格式：`位置（ID 或时点）→ 证据 → 观众或制作影响 → 最小修复 → 责任层 → 保留项`。

**TTS 输入**：朗读文本与台词不同（数字读法、停顿）时，对白表记录 TTS 输入文本，台词不变。
**响度**：以测量值验收（积分响度与真峰值），偏差超过 ±0.5 LU 时二遍归一化；不以滤镜设定值代替测量。
**编辑复验**：只复验改动区域与其依赖，保留编辑前后对照作为证据。

**PROVISIONAL 升级**：完成真实观看或聆听 → 按分模态清单逐项勾选 → 重写结论并附证据位置。无法听的模态，声音相关项保持 PROVISIONAL（SKILL §5）；可测指标（时长、响度、削波、静音段）是辅助证据，不替代听感。

**导演判断前的安全网**（写完后逐条自查；每条都指向已写下的字段，不依赖外部工具）：档位与实际叙事跨度相符？ID 唯一且可追溯？（T2）承接上集 Snapshot？道具有位置与持有链？时间与光态连续或有例外？相邻镜的入点与出点是否承接（维度见手册 §3 接缝清单）？物品状态与动作阶段是否跨镜可衔接、变化有无来源？角色按当前知识行动？每行对白有 voice_id 绑定？每镜有职责？时长闭合？进入生产前写了能力声明？未检查的媒体是否标为 PROVISIONAL？MEDIA 行是否写了可与契约比对的输出规格？
