# Presentation / Editorial Art Direction：让项目被准确地理解（仅按需读取）

只在用户要求项目提案、世界观手册、角色册、Lookbook、分镜展示、发行封面、赞助/投资 deck 或交付说明时读取本文件。Presentation 是 Canon 与 Intent 的派生视图（SKILL §06），不是另一套创作脑；它可改变如何说明作品，不能静默改写 Canon、Character DNA、World State 或 Directorial Intent。

## 1. 判断链与工艺

先判断：

`Audience → Objective → Message → Insight → Visual Concept → Focus → Information Weight → Spatial Structure → Composition → Media`

- **Audience / Objective**：谁看、已知什么、要做何种理解/决策/行动；不是“把资料做漂亮”。
- **Message / Insight**：每份材料有一个核心主张；每页有一句可检验结论和一个主视觉重心。结论、证据、条件、来源不能拥有同等音量。
- **Visual Concept**：从本作品的 Canon、媒介、时代、角色和 Directorial Intent 推导色彩、类型、材料、图像距离与版式语气；不是另贴“高级/科技/电影感”滤镜。
- **Spatial Structure / Composition**：阅读路径、网格、比例、对齐、留白、裁切和文本/媒体关系服务焦点。卡片墙、厚容器、无意义边框、阴影、渐变、图标和装饰默认删除，除非承担信息或叙事职责。
- **Media**：图片、图表、角色图、剧照、视频、材质或动效只在提供证据、语境、尺度、情绪、过程或品牌表达时存在。无任务的媒体删掉；画内事实、角色状态、产品/空间结构仍服从 Canon。

借鉴 Swiss Typography 的清晰层级、FT/Bloomberg 的事实与数据责任、McKinsey Editorial 的结论/论证、Apple/Aesop/Pentagram 的材料/比例/品牌语气，以及电影语言的观看立场、空间压力、真实光影、色彩与景深；这些是判断尺度，不是可复制的表面风格。图表和文字必须诚实可读，颜色不应是唯一编码。

交付前以 3 秒/10 秒/30 秒检查：先看到的焦点是否正确？能否说出本页结论和证据？条件、来源和下一步是否仍可读？实际导出未查看时，只能声明设计已检查，不能称演示已通过。

## 2. 页面记录与 stale（P-）

- 页面用 `P-` ID，绑定其主张、引用的 Canon/资产/媒体、唯一焦点、信息层级、媒体用途与交付状态；页面不是新 Context。
- 其引用目标（Canon/Intent/DNA/资产/媒体）任一变化，页面自动标 `stale` 并按需刷新；页面表达的变化不传播到故事事实。
- 页面的真实图片/视频、字体、来源、版权/肖像、导出文件与可读性观察仍放在 `制作/` 的对应交付范围；不能用 deck 文件名、缩略图或设计说明冒充已检查的媒体/授权事实。
