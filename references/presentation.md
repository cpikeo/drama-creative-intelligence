# Presentation：让作品被准确理解（仅按需读取）

仅当用户要求项目提案、世界观手册、角色册、Lookbook、分镜展示、发行封面、投资或合作 deck 时读取。Presentation 是 Canon 与 INTENT 的派生视图：它可以改变如何说明作品，不能改写 Canon、角色 DNA、World State 或 INTENT。

## 1｜判断链

`受众 → 目标 → 主张 → 洞察 → 视觉概念 → 焦点 → 信息权重 → 空间结构 → 构图 → 媒体`

- **受众与目标**：谁看、已知什么、要做出什么理解、决定或行动。目标不是“把资料做漂亮”。
- **主张**：每份材料一个核心主张；每页一句可检验的结论和一个视觉重心。结论、证据、条件与来源不得同等音量。
- **视觉概念**：从作品的 Canon、媒介、时代、角色与 INTENT 推导色彩、类型、材料、图像距离与版式语气。不贴“高级”“科技”“电影感”之类的通用滤镜。
- **空间与构图**：阅读路径、网格、比例、留白、裁切与文本、媒体的关系服务于焦点。卡片墙、厚边框、阴影、渐变与图标默认删除，除非承担信息或叙事职责。
- **媒体**：图片、图表、剧照、视频只在提供证据、语境、尺度、情绪、过程或品牌表达时存在。画内事实、角色状态与空间结构仍服从 Canon。

**工艺参照**（判断尺度，不是可复制的表面风格）：清晰层级与比例（瑞士排版）、事实与数据的责任（结论先行、证据可追溯）、电影的观看立场与真实光影。图表与文字必须诚实可读，颜色不是唯一编码。

**交付前检查**（3 秒、10 秒、30 秒）：先看到的焦点是否正确？能否说出本页结论与证据？条件、来源与下一步是否仍可读？未导出查看的，只能声明“设计已检查”，不能称“演示已通过”。

## 2｜页面记录（P-）

- 每页绑定：主张、引用的 Canon、资产或媒体、唯一焦点、媒体用途、交付状态。页面不是新的 Context。
- 引用目标（Canon、INTENT、DNA、资产、媒体）任一变化，页面标 `stale`，按需刷新；页面表达的变化不传播到故事事实。
- 页面里的真实图片、视频、字体、来源、版权与肖像，仍归 `制作/` 对应的交付范围。不能用文件名、缩略图或设计说明冒充已检查的媒体与授权。
