# 作品质量评价量表（人工盲评，非关键词计分）

用途：当需要对比两个版本（或两次创作运行）的作品质量时，用本量表做独立盲评。
`lint.py` 只能检查确定性规则；本量表覆盖无法机器化的艺术判断。

## 0｜适用边界

- 适用：同一任务、同一预算口径下，对两份产出（如重构前 / 后）做质量对照。
- 不适用：用关键词命中率、格式通过率代替作品质量；用单一作者自评代替盲评。
- 评审者须盲于版本标识；两名独立评审；分歧超过 1 分时必须讨论并记录分歧点，不得取平均了事。

## 1｜维度与锚定（每维度 1–5 分）

| 维度 | 1 分锚定 | 3 分锚定 | 5 分锚定 |
|---|---|---|---|
| 原创性 | 关键选择来自题材惯例，观众可预猜下一步 | 至少一个关键选择不可用惯例解释，但动机交代不足 | 多个关键选择只能从本作机制与人物长出，且观众无法用"这类故事都这样"预猜 |
| 戏剧张力 | 事件彼此独立，无出去压力 | 有因果，但至少一处张力靠信息隐瞒硬撑 | 每场由上一场的出去压力推出，张力来自人物选择与代价 |
| 人物可信度 | 行动可替换为任何人 | 行动大体可信，至少一处策略跳变无因果 | 关键行动全部通过行动门，换人测试不成立 |
| 视听意图 | 镜头、光、声无明确服侍对象 | 多数镜头有功能，偶有装饰性镜头 | 每一镜都能说出服侍谁；静止帧成立；无滤镜式电影感 |
| 美术与摄影 | 服装道具与时代脱节，光影无动机，画面静止不成立 | 美术与摄影基本服务叙事，偶有统一感瑕疵 | 视觉主张统一可辨识；材质可信；光影有动机；曝光与肤色稳定；特效合成与画面无缝 |
| 跨镜连续性 | 相邻镜的人物、位置、方向、景别或光态无承接，画面像素材拼接 | 主线可连，但至少一处接缝漂移（方向反了、景别跳变、光态冲突）需观众自行补全 | 每一处切镜都能说出承接什么、改变什么、为何改变；越轴与跳切有声明与回归锚点；同角色跨镜始终是同一个人；物品状态与动作阶段跨镜可衔接 |
| 跨集连续性 | 事实、道具、知识、承诺断裂或凭空恢复 | 主线连续，细节（伤痕、持物、知识）偶有漂移 | 关键物件、伤痕、知识与承诺的后果全部可追溯到 ID |
| 生产完成度 | 规格缺失或媒体与规格不符 | 规格完备，媒体存在未经验收 | 三层 QA 俱全且基于真实观看 / 聆听；PROVISIONAL 标注诚实 |
| 情绪穿透力 | 情绪靠音乐与台词外宣 | 情绪节拍部分由人物代价承担 | 删掉音乐与镜头处理，情绪链条仍成立 |

## 2｜协议执行深度（与 lint 规则对应，可机器核对）

逐行核对 `lint.py` 的 P1–P14 是否全部通过；凡 lint 未覆盖的协议条款
（如时长闭合、表演可读性、VO 信息权限），由评审者抽查 3 处并记录。

## 2b｜真实连续画面核查（必须人工观看，不得以单帧截图代替）

针对已生成的真实媒体，按顺序检查并记录证据位置（帧号 / 时码 / 文件）：

| 核查项 | 怎么看 | 通过标准 |
|---|---|---|
| 人物身份稳定性 | 同一角色跨镜并排抽帧，与 REF 组对照 | 脸、发型、体态、服装、配饰、伤痕侧别与位置一致；差异能指认触发事件 |
| 动作连贯性 | 播放相邻镜的动作衔接处，逐帧看手、重心、持物 | 动作起止接住，无跳变、回弹、穿模；持物不凭空出现或消失；未完成的动作从可衔接状态继续 |
| 物品静动一致 | 对照镜头卡的固定物 / 可移动物 / 环境动态分类逐镜核对 | 固定物位置形状结构不变；可动物变化有动作或外力；环境动态有来源；无瞬移、复制、消失、穿透与数量跳变；切镜不重置物品状态 |
| 空间可信度 | 对照 LOC 空间结构与陈设，检查遮挡、比例、纵深 | 同一场景的结构、陈设、材质、人物比例一致；未知背面未被伪造 |
| 光影统一性 | 对照状态表逐镜看光源方向、色温、对比、肤色曝光 | 同场同时段一致；跨镜变化有状态表依据 |
| 视觉风格一致性 | 与美学锚点逐镜比对色板、颗粒、媒介质感 | 无风格漂移；变化有事件或 DEC |
| 剪辑自然度 | 完整连续看成片，不暂停 | 切镜有意图；越轴与跳切有声明；不出现需要观众自行补全的断裂 |
| 情绪连续性 | 静音看画面、闭眼听声音、正常看一遍 | 情绪节拍跨镜连续；反应镜头提供新信息 |

未生成、未观看或未聆听的项，只能记 `PROVISIONAL`，不得计入分数。

## 3｜记录格式

每份评价记录：任务输入、两份产出的标识（盲标 A/B）、九维度各两名评审的分数、
分歧讨论记录、媒体证据位置（时码 / 帧号）、成本账（见下）、总体结论（A 优 / B 优 / 无差异）。
不得只给一个加权总分而不公开分维度分数。

**成本账**（每个版本各记，用于判断优化是否值得）：输入 token（按任务口径计量）、
生成次数（按模态分列）、返工次数（按责任层分列：事实 / 判断 / 规格 / 媒体 / 剪辑）、
媒体费用或等价成本、人工观看时长。缺项写"未测量"，不得填 0 冒充已测量。
