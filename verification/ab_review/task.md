# A/B 对照固定任务 T-AB1

同一任务、同一预算口径，分别在 `skill-v7.1.0` 与 `skill-v7.2.0` 两个技能版本下各完成一次。
任务经过专门设计，使 v7.2.0 新增的能力（视觉主张、电影摄影、表演层次、艺术方向、视觉特效与合成、空间声场）成为**可被评审的产出差异**。

## 输入（一句话）

> 深夜旧灯塔里，守灯人发现每次擦亮灯罩，海雾就会退去一分——而灯塔的影子里，始终站着一个他认识的人。

## 固定口径（两版本相同，不得擅改）

- 媒介与交付：竖屏 9:16 动态漫短剧，单集约 90 秒，1080x1920，H.264 + AAC，目标响度 −16 LUFS ±0.5。
- 产出范围（规格层）：创作总控（契约、世界 Bible、A/B 级角色 DNA、Canon、承诺账、INTENT、图谱、资产与 LOCK）＋ EP001（三场戏的剧本、镜头卡、对白表、状态表、图谱增量、Snapshot Diff、QA、生产追踪）。
- 字数上限：创作总控 ≤ 1200 字；EP001 ≤ 2500 字。
- 禁止生成真实媒体。MEDIA QA 与 CUT QA 双版本均为 PROVISIONAL，不参与对比。

## 任务要求（每条对应一个待检验的能力）

1. **视觉主张**：创作契约中一句话陈述本作视觉主张。
2. **艺术方向**：世界与美术设定须体现统一的时代质感与材质语言（如 1970 年代灯塔、铜绿、雾、油灯），并说明视觉层级如何服务每镜重心。
3. **表演层次**：至少一场戏的表演须体现层次推进（克制—松动—爆发），情绪转折有可指名的触发。
4. **电影摄影**：至少一个镜头须说明画幅内的曝光与透视动机（如灯罩强光下守灯人肤色曝光不漂移、灯塔空间纵深可信），并写明机位与运动理由。
5. **视觉特效与合成**：设计一个有叙事动机的特效/合成元素（如雾中光束、影子的合成），写明它与原画面如何统一（光源、材质、景深、颗粒、运动模糊、遮挡），并说明为何后期修复优先于重生成。
6. **声音设计**：声音设计须含空间声场（海浪距离、雾笛方位、房间感），并与画面空间一致。
7. **连续性**：角色各一名（A 级守灯人、B 级影子里的人），含 Voice DNA 与配音锁；承诺账至少两条；图谱增量与 Snapshot Diff 完整。

## 评审

双人独立、盲于版本，按 `../rubric.md` 八维度各自打分并写证据。主持人持版本对应表，回收后解盲。
