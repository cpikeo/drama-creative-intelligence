# A/B 对照固定任务 T-AB2：视觉连续性与角色一致性

回答一个具体问题：**v7.3.0 新增的跨镜接缝规则（入点/出点、越轴声明、跨场依据、
跨镜身份与空间漂移的责任层）是否买到了更可信的连续画面与角色一致性？**

对照锚点：`skill-v7.2.1`（无接缝规则）vs `skill-v7.3.0`（有接缝规则）。
固定口径、评审方式与诚实边界见 [README.md](README.md) 与 [../rubric.md](../rubric.md)。

## 输入（一句话，两版本相同，不得擅改）

> 深夜渔港，替班的女焊工发现：她每晚补好的那道裂缝，第二天总出现在另一个人身上——而今晚，裂缝出现在她弟弟的船上。

## 固定口径（两版本相同）

- 媒介与交付：竖屏 9:16 动态漫短剧，单集约 90 秒，1080x1920，H.264 + AAC，目标响度 −16 LUFS ±0.5。
- 产出范围：创作总控（契约、世界 Bible、A/B 级角色 DNA 含配音锁、Canon、承诺账、INTENT、图谱、资产与 LOCK）＋ EP001（剧本、镜头卡、对白表、状态表、图谱增量、Snapshot Diff、QA、生产追踪）。
- 生成预算（两版本相同，写入成本账）：图像关键帧 ≤ 12 张 / 角色；视频 ≤ 6 段 / 5 秒；TTS ≤ 12 句；编辑修复不占生成预算。
- 禁止：为掩盖接缝问题而重复整镜重投；跨镜更换角色参考图；无 DEC 的风格切换。
- 字数上限：创作总控 ≤ 1200 字；EP001 ≤ 2500 字。

## 七个场景（T-C1 – T-C7，每个场景对应一类连续性风险）

每个场景单独成镜卡，并在 QA 中给出该场景的接缝结论。同一场景在两版本下用同一输入。

| ID | 场景 | 必须出现的连续性判断 | 主要评价维度 |
|---|---|---|---|
| T-C1 | 连续动作：女焊工蹲下、补焊、起身，跨 3 镜 | 动作起止与重心承接；持物（焊枪）不消失；手部特写与中景的手位一致 | 动作连贯性、跨镜连续性 |
| T-C2 | 多镜头对话：与弟弟的正反打 + 一个过肩 | 视线相对、轴线不无故越轴、景别成序列、两人距离变化有事件 | 跨镜连续性、人物可信度 |
| T-C3 | 人物转身与移动：从船坞走向码头，同场 4 镜 | 运动方向与屏幕方向一致；越轴须指名越轴点与回归锚点；走位距离变化有因 | 跨镜连续性、视听意图 |
| T-C4 | 同角色不同景别与光线：近景（舱内手电）、中景（舱口）、远景（码头灯） | 身份跨镜稳定（REF 对照）；肤色曝光不随景别与机位漂移；光态变化有状态表依据 | 人物身份稳定性、光影统一性 |
| T-C5 | 跨场景转换：船坞 → 码头 → 船舱 | 跨场接缝声明转场性质或事件依据；LOC 空间结构与陈设一致；时间跳跃有状态表行 | 空间可信度、剪辑自然度 |
| T-C6 | 图生视频：以已验收关键帧为首帧生成一段补焊视频 | 首帧等于已验收关键帧；视频出点与下一镜入点对齐；动作起点、触发、过程、终点明确 | 动作连贯性、生产完成度 |
| T-C7 | 角色状态变化：弟弟手背新增焊痕（按六段链） | 外观变化有触发事件、代价与生效范围；伤痕侧别与位置近景可辨；变体可还原 | 人物身份稳定性、跨集连续性 |

## 评审

1. 两名独立评审，盲于版本，按 [../rubric.md](../rubric.md) 九维度各自打分并写证据
   （新增「跨镜连续性」维度；媒体项按 rubric §2b 真实连续画面核查逐项记录帧号 / 时码）。
2. 主持人持版本对应表，回收后解盲；分歧 >1 必须讨论并记录。
3. **机器核对（两版本都跑 v7.3.0 的 lint）**：`python3 verification/lint.py --project <产出>`。
   v7.2.1 的产出没有接缝字段，预计在 P13/P14 失败——这是"旧版允许接缝不被写下"的
   机制证据，不等于作品更差；作品质量只以九维度盲评为准。
4. 成本账按 rubric §3 逐版本记录（token、生成次数、返工次数与责任层、媒体成本、观看时长）。

## 诚实边界

- 本环境没有媒体生成工具、没有第二位独立评审时，T-AB2 的媒体层与盲评**不得执行**，
  只能在 CHANGELOG 记"未执行"；不得以规格层的自评冒充连续画面已验证。
- 场景表是风险清单，不是镜头配额；评审不得因为"某版本多写了字段"而加分，
  只能因为它让连续画面更可信而加分。
