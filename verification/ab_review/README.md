## 诚实边界（不可伪造的部分）

- **双人盲评本身必须由两名独立人类评审完成**；本环境没有第二位评审，不得由同一作者扮演两名评审、不得用关键词命中率替代。
- 本环境**没有媒体生成工具**，因此 T-AB1 只覆盖创作与规格层（SPEC QA）；MEDIA QA / CUT QA 双版本均为 PROVISIONAL，不参与对比。
- 主持人不参与评分；评审员在解盲前不得知道 A/B 对应关系。
- 结论必须公开八维度的分维度分数，不得只给加权总分（见 [../rubric.md](../rubric.md) §3）。
